# Project summary for recruiters

## Dispatch Desk — Delivery Confirmation Automation

**Role:** Independent Python/backend automation project

**Objective:** Reduce manual customer follow-up by automating delivery confirmation, rescheduling, reminders and staff escalation.

**Stack:** Python, Streamlit, SQLite, PostgreSQL, WhatsApp integration design, HTTP APIs, background workers, GitHub Actions.

**My engineering focus:**

- Modelled delivery states and customer-response workflows.
- Built an interactive Streamlit demo with simulated customer and carrier behavior.
- Designed a persistent backend with scheduled jobs, worker recovery and audit events.
- Implemented duplicate protection and conservative handling of uncertain external sends.
- Documented integration boundaries, operational failure modes and safe rollout requirements.
- Added automated checks for backend and demo behavior.

**What it demonstrates:** Practical backend design, API integrations, workflow automation, operational reliability, and the ability to distinguish a working simulator from production-ready external integrations.

**Current status:** Demonstrable project with private source; live provider setup and carrier-specific production integration are separate deployment tasks.
